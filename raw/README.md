# raw/

Immutable source material for the wiki: articles, notes, transcripts, journal entries, PDFs. Once a file lands here it is never edited — if something changes, add a new file or a follow-up note rather than modifying the original. This is the source of truth the wiki is derived from.

Images and other attachments go in `raw/assets/`.

Drop a new source here and ask Claude to ingest it — see the ingest workflow in the root `CLAUDE.md`.
